PostgreSQL 是世界上最先进的开源数据库，也是极少数真正由社区驱动、不被任何一家公司攥在手里的开源项目。老冯一直觉得，开源项目的灵魂在社区，不在代码。

所以今天想聊一件憋了很多年的事：**复兴 PostgreSQL 中文社区。** 这个念头几年前就有了，但一直没好意思大声说。因为光喊口号没意思，手里得有东西。今天总算有点东西能拿出来了，那就先从一件下周就能看到的事说起。

## 复兴隐含着没落

说“复兴”，隐含的前提就是“没落”。这一点，老冯是感到遗憾的。PG 中文社区几年前还算活跃，这几年声音越来越小、动作越来越少，一年也冒不出几个泡。在 PostgreSQL 全球蒸蒸日上的当下，这种反差相当刺眼。

中文社区以前的主席，是我的前合伙人和同事，圈子里的朋友我也基本都认识。早在 2018 年，我就多次提议社区为用户做点实事：

1. 做一个 PG 的国内下载镜像源。那时候很多镜像站还没有 PGDG 的仓库。
2. 做好文档汉化。当时有人在翻，但经常落后几个大版本，滞后一两年。
3. 做一个社区自己的 PostgreSQL 发行版，用它凝聚一个小的开发者群体。

后来的事大家也知道了：这些事没做起来，社区忙着办会办沙龙，声音越来越小，社区本身也越来越沉。原因当然有很多，老冯说两个我看得最清楚的。

**一是国产数据库运动把人分走了。** 一大堆数据库基于 PG 魔改、换皮、套壳，很多干脆不承认自己是 PG。比起参与公共建设，大家更关心自己那一亩三分地。举个例子，openGauss 早年还承认自己是 PG 社区的一份子，后来对外讲 100% 自研，就自立门户了，也带走了一批人。几轮分化下来，社区元气大伤。

**二是没有以用户为本。** 大会越来越像展销会，以前一年还能办几场活动，后来连每年的大会都办不起来了。就算办起来，也越来越像各家产品的广告会：厂商轮番上台打广告、吹牛逼，台下用户听完也拿不到什么能用的东西。这种会更像是厂商一年碰个头、聚个餐，而不是一场面向用户的会议。

最后的结果，就是**空心化**。这个社区到底给用户提供了什么？

提供文档吗？社区版的中文翻译，印象里停在了 PG 15。提供软件下载仓库吗？没有。后来阿里云、腾讯云、清华这些镜像站倒是有了 PGDG 仓库镜像，但上游一断更，这些仓库也跟着断了好几个月。最后还得老冯自己跑去做镜像站。公开批评了一次之后，有几家跟上来了。但那是厂商和高校自己的事，也跟社区没什么关系。

[卡脖子：PostgreSQL切断镜像站同步通道](/pg/pg-mirror-break/)

[从PG“断供”看软件供应链中的信任问题](/pg/pg-mirror-pigsty/)

提供大会？连这个都渐渐办不起来了。

## 社区的根，在用户

那一个社区，到底应该是什么样的？Percona 的老板 Peter Zaitsev 讲过一个观点，大意是：开源社区分三个圈层，**开发者社区、厂商社区、用户社区**。很多人忙着经营厂商社区，但用户社区才是根。

按这个标准去看 PG 中文社区，问题就很清楚了。中文**开发者社区**，基本搞不起来。PG 是全球开发者共同贡献的，中国在 PG 生态里能拿得出手的项目本来就不多。

**供应商社区，搞过，散了。** 中文社区实际上活成了一个厂商联盟，一个行会性质的松散社团。可就连这个功能，也随着国产化信创运动而变得无足轻重，各家都开始各玩各的。

**用户社区，从来没被认真做过。** 而这恰恰是最广泛、最根本的那一层。

PG 的世界本来就细分成很多块：内核开发者社区、厂商社区、用户社区。用户社区又可以按国家、城市、语言来分。PostgreSQL 中文社区，本该是其中最典型的那种：一个覆盖整个中文世界的用户组。

用户组该干什么？其实一点也不玄：**用户需要什么，就做什么。** 一个中文用户真正需要的，无非是这些：

- 一个开箱即用的发行版
- 跟得上版本的中文文档
- 稳定可靠的国内镜像仓库
- 完整的中文消息本地化
- 一个中文门户网站
- 一个能交流、能求助的本地社群

这份清单，跟我七八年前提的那几条，几乎没变。

## 还是得自己上

以前我没去碰这个事，是因为觉得活太多，一个人干不了。后来发现，真倒不一定。

**你说中文社区没有拳头产品？** 那老冯的 Pigsty，现在大概是中国在 PG 生态里最能拿得出手的开源项目。在全球 PG 发行版这条赛道上，它占住了一张门票，GitHub Star 也是 Linux 原生 PG 发行版中的第一。它解决的是用户最大的痛点：用不起来。从裸机到一套生产级的 PostgreSQL 服务，高可用、备份恢复、监控、扩展一键拉起，相当于一个开源的企业级 RDS。围绕它，也聚起了一个将近三千人的小社区。

**[打造一个立足中国，面向世界的PG数据库发行版](/pg/forge-a-pg-distro/)**

**你说没有中文文档？** 那老冯自己带着 Agent，把 PostgreSQL 从 6.3 到 20 三十来个大版本的官方文档，全部翻成了中文，还配了一个更好用的全文检索。Patroni、pgBackRest、PgBouncer、pgBadger 这些周边组件的中文文档，也一并维护着。

[PG 中文文档发布：11 个大版本，一个不落](/pg/pgsql-cc-online/)

[PostgreSQL 18,17,16,15,14 中文文档发布](/pg/pgdoc-cn/)

**你说消息本地化半半拉拉？** 简体中文已经进了 PG 19 Beta 4，繁体中文跟着 RC1 发。自动翻译与跟进的工作流也建设起来了，从 PG 19 开始，中文覆盖将不再是一个问题。

[PostgreSQL 中文版来了！](/pg/pg-nls/)

[为什么要做 PostgreSQL 汉化？](/pg/pg-zh-tw/)

**你说没有国内仓库？** 老冯维护着一个 PGDG 的中国区仓库与镜像，放在 CDN 上免费给大家用。在 16 个 Linux 平台上打包、分发了 PG 生态里近 600 个扩展和软件包，月下载量过百万。

[PostgreSQL神功大成！最全扩展仓库](/pg/pg-ext-repo/)

[PG内核与扩展包管理神器](/pg/pig/)

**你说没有中文门户？** 中文社区站和 PG 知识库也做好了：[pgsql.cc](https://pgsql.cc/)，每日跟进 postgresql.org 上游权威消息，带有一个更好的中文全文检索，独特的 PG 知识图谱，还有一个每日新闻栏目，已经更新半年多了。

[PostgreSQL 官网中文版：pg.center](/pg/pg-center/)

[PostgreSQL 中文站，再加一份日报专栏](https://mp.weixin.qq.com/s?__biz=MzU5ODAyNTM5Ng==&mid=2247493166&idx=1&sn=67e34928473b23e7cbf6169f9e0260cb&scene=21#wechat_redirect)

**你说中国开发者在 PG 世界没声量？** 那就得去现场参会、跟人面对面交流，才能发出声音、建立信任，进而推动一些事情。这几年也确实推动了一些：

- 老冯做的 PG 扩展目录，现在不只 Pigsty 在用，全球不少 PG 厂商和服务商也在用。参见：[扩展，为所有人而构建：PGConf.Dev 2026 演讲](/pg/extensions-for-everyone/)
- [推动龙芯（LoongArch）架构进入了 PostgreSQL 官方 APT 仓库](/pg/pg-apt-loong64/)
- [PG 对 GB18030 的支持有瑕疵，推动上游修掉了](https://mp.weixin.qq.com/s?__biz=MzU5ODAyNTM5Ng==&mid=2247487665&idx=1&sn=7792bc69e14bdcd606ec7780ed087101&scene=21#wechat_redirect)
- Rust 扩展也开始进入 PGDG 仓库，Devrim 从咬死不让一个 Rust 扩展进去，现在 Rust 写的 anonymizer 也进了 Yum 仓库。

我想说明的只有一点：这是可能的。中文 PG 世界，现在有了一个有凝聚力的开发者社区，有自己的项目，在全球社区里也有声音、有代表。

## 能力不再是瓶颈，愿力才是

放在几年前，上面不少事儿，每一件都够一个小团队忙活几个月。三十一个全量历史大版本的文档翻译、六万多条消息的本地化、16 个平台的打包分发，光靠一个人的两只手，就像愚公移山一样。

但现在有 AI 了。Agent 能干活，而且能干很多活。一个人带一群 Agent，能做到以前一个团队才做得到的事。当能力不再是问题，关键就变成了另外两样东西：**你想把它做成什么样的愿景，以及你愿不愿意去做的愿力。**

如果只是奔着商业目的，比如“我就要办个大会、收点赞助费”，那大概率做不成，做成了也没意思。但如果是出于热爱，希望更多人能用上 PG、用好 PG，这件事就可以做，也就做得成。热爱和愿力是独一无二的。在这个 AI 什么都能干的时代，它恰恰是最替代不了的东西。

## 我想复兴的，是一个用户社区

提前说清楚：**老冯对搞厂商社区没兴趣。** 去各家化缘、拉赞助、办展销会的模式早就有了，现在也有人在搞，所以我也不会去做。我真正想要做的是：如果你是一个 PostgreSQL 用户，这里的资源能帮到你；你遇到的问题、你的想法，有一个地方可以和大家分享交流。

用户社区要有切实的价值主张，不能空洞地说“服务 PG 用户”，却说不清到底提供了什么服务。所以发行版是核心，中文文档、中文本地化、中文社群围着它配套。还有一点：**中文社区，不等于中国大陆社区。** 台湾、新加坡、马来西亚，都有大量的中文用户。这次本地化把繁体中文一起做了，也是这个意思。老冯在 PG 社区里也认识不少台湾、东南亚的朋友，这个圈子本来就应该属于整个中文世界。

接下来，我想陆续把这些东西补上：

- 一套完整的中文上手教程
- 一些真实、有趣的用户案例
- 不定期的播客与分享

## 众人拾柴火焰高

最后说句实在话：有 AI 加持，一个人能干很多事，但很多事依然不是一个人能解决的。

软件与扩展需要测试，翻译需要有人挑错，案例需要真实用户来讲，社群需要有人愿意回答别人的问题。社区之所以叫社区，就是因为它不属于某一个人。所以，老冯负责先起个头，剩下的，还是要靠众人拾柴火焰高。
