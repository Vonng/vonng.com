T3 Code 是 Theo 团队做的一款开源 Coding Agent Harness 控制面，MIT 协议，能把 Claude Code、Codex、OpenCode、Antigravity 这些工具统一收进一个界面里调度。这东西我最近自己也在用。现在市面上的 Agent harness 五花八门，在这种聊天交互形态的开源工具里，T3 Code 算得上是第三方做得最好的了。特别是最近 Gemini 雄起，但 Antigravity 屎一坨，而 T3 Code 这边还能直接用上，用户一下就蜂拥而至了。

结果这么一个挺好用的开源项目，这两天却在推特上跟中文社区干了一架。我看完全程，结论就一句话：当事人 19 分钟就解决完的事，场外看客硬是演成了一场大型玻璃心现场。

## 来龙去脉

事情其实很简单，来龙去脉就这么几步：

1. **11 月 20 日**，推上的“开源小新”发布了“T3 星尘版”。这是他第一次公开发开源项目，基于 T3 Code 做了不少魔改，简介里注明了自己改的，但仓库名、软件名、图标都还挂着 T3。
2. **11 月 23 日下午**，博主“夙愿学长”把这个魔改版当成官方版发推吐槽：同一屏里挤着两个 Ask 输入框，待处理会话上下重复显示，界面乱七八糟。
3. **当晚 7 点多**，Theo 转发了这条吐槽，称外面流传着一个 “Chinese knockoff”[^1]，这绝对不是他们做的 App；过了十来分钟，又补了一句：“Temu3 Code”[^2]。
4. **紧接着**，小新回复说“会考虑改个不那么容易误会的名字”。Theo 直接顶了回去：“Not consider. Do it right now”[^3]，否则就找 GitHub 封号。
5. **19 分钟后**，小新麻利地把仓库改名为“星尘 Agent”，清掉了所有 T3 的名字、标识和图标，明确标出是非官方分支。吐槽的博主也下了官方原版实测，公开道歉[^4]，承认让官方背了锅。小新和 Theo 私下聊了不少，后来专门发推说明：“烂我接受，批评我接受”[^5]，并强调“我跟 Theo 昨天到今天一直在聊，我们两个没有矛盾”[^6]。

按理说，这事到这儿就该画上句号了：误会解开，名字改了，当事人握手言和。

结果第二天，中文推圈炸了。“Chinese knockoff” 和 “Temu3” 被反复截图批斗，种族歧视的帽子满天飞，还有人翻出 README 里那句 `If you don't like something, fork it`，指责 Theo 双标。

Theo 本来就不是好脾气的主，被围攻了一整天直接上头，连发几条硬刚[^7]，坚称自己没做错，甚至在气头上开始反唇相讥。当天中午，T3 Code 仓库补了一份 `TRADEMARK.md`，README 也改成了 `fork it under your own branding`。

## Fork 是权利，商标不是

剥开情绪，底下其实是一个最基础的开源常识：**代码可以拿走，名字不行。**

MIT 协议授权给你的只是代码——随便用、随便改、随便分发，甚至拿去卖钱都没问题。但它管的是著作权，不管商标权。你 fork 一个项目，不代表继承了它的声誉，更不代表拥有它的品牌使用权。

这是开源社区的习惯法，很多小项目一开始甚至懒得单独写一份商标声明，因为默认圈里人都懂。Debian 当年打包 Firefox 改名 Iceweasel，Redis 改协议后社区 fork 出来叫 Valkey，Terraform 的分支叫 OpenTofu，Elasticsearch 的分支叫 OpenSearch。稍微有点体面的开源项目，没有一个是顶着原厂招牌出去混的。

道理再朴素不过：如果你不改名，把人家的东西 vibe coding 改成一坨屎，用户分不清真假，跑去对着原作者破口大骂，换谁坐在这个位置上都得炸毛。这次就是现成的例子——截图里的低级 Bug 是魔改版干的，当着几万人的面挨骂的是 T3 团队。

老冯自己做开源、fork 别人项目，也是按这个规矩办的。做对象存储 MinIO 的社区分支时，说实话，我一开始真不想改名——仓库、包名、容器镜像、文档、用户脚本，全套动一遍麻烦得要死。可 MinIO 是人家白纸黑字的注册商标，所以该改就得改，老老实实叫成了 **Silo**。

[Silo 发布：兼容 S3/MinIO 的开源对象存储](/db/long-live-silo/)

当然也有懒得改名的，比如最近[我接盘维护的 VectorChord](/pg/maintain-vchord/)（PG 向量扩展），就继续沿用了原来的 `vchord` 名字。但那是因为事先确认过三件事：第一，原作者不介意、不会来告；第二，对方没注册商标；第三，其实还是用扩展名 `vchord` 替换了原来的品牌名 VectorChord。三条都稳妥，才省了折腾。

有人拿 Anthropic 举例子，说 Claude Code 借鉴了 T3 的侧边栏设计，Theo 大度地说“万亿公司用也没关系”，轮到中国个人开发者就威胁封号，这是双标。这逻辑压根没转过来：Anthropic 借鉴的是功能交互，又没把 Claude Code 改名叫 T3 Code。抄功能随便，冒招牌不行，这恰恰用的是同一把尺子。

至于开源小新本人，我觉得他处理得挺体面。第一次发开源项目，不懂商标规矩很正常；被指出来，19 分钟完成清理改名，面对批评也大大方方认账，事后跟原作者沟通得挺顺畅。一个指正，一个立改，本来是个挺良性的开源互动。

## 开源是产销合一，白嫖瞎骂是负资产

整场闹剧看下来，让我观感最差的，既不是嘴欠脾气冲的 Theo，也不是不小心踩坑的开源小新，而是场外那群义愤填膺的看客。（骂的太难听，就不截图了）

开源社区的本质是 **Prosumer（产销合一）**：大家一起生产软件，一起使用软件，本质上是给自己造工具。在这个生态里，写代码、修 Bug、做维护的人是主角。如果你只是纯粹的消费者（Consumer），愿意掏钱赞助、帮忙传播口碑，或者提几个靠谱的 Issue，那也是正贡献。

但用着人家的免费软件没掏一分钱，连原版和第三方魔改版都没分清，就跑去原作者评论区指点江山、逼人家道歉，这种用户对开源生态来说就是纯纯的**负资产**。开源软件又不是求着你用的。T3 Code 官网上甚至大大方方挂着一个 `Steal our code (legally)` 的按钮，欢迎你合法把代码搬走，唯一的要求只是别顶着人家的牌子砸场子。连这点体面都不讲就实在太难看了。

## “拼夕夕版”是个好玩笑，但架不住上纲上线

再看把大家点着的那句 “Temu3 Code”[^8]。

Temu 就是拼多多海外版，在英文互联网里几乎等同于廉价平替。一个把界面改成同屏双输入框、会话上下重影的山寨分支，被吐槽一句“拼夕夕版 Code”，老实说，我觉得挺幽默，也挺形象，就两个词，精准到位。咱们中文互联网自己天天调侃“拼夕夕版 XXX”，嘴比这毒多了，也没见谁觉得受到了人格侮辱。东西确实粗制滥造，被损一句，笑一笑把 UI 修好就是了。

当然，这事往后发展，被一群中推拱火，Theo 确实也被彻底激怒了。起初那句 “Chinese knockoff” 把国籍挂在前面，要求立刻改名的语气也冲，本来就是一句带刺的吐槽加上维权心切。结果中文圈一群人扑上去疯狂上纲上线、扣 racist 大帽子，直接把人家点着了。到了第二天，他在围攻之下彻底反弹，不仅骂社区“敏感到不行”[^9]、反问一句玩笑怎么就成了种族歧视[^10]，甚至在气头上把炮火扫向了整个群体，发帖嘲讽什么“中国开发者被允许偷商标”之类的话，开始攻击起所谓的 Chinese style。

说句实在话，看到他后面那些针对中国开发者的气话，我看着也挺不高兴的。谁乐意看见自己所在的群体被一竿子打翻？但难受归难受，我也理解他为什么会有这种行为：人家本来只是冲着一个冒名顶替的 Bug 截图去的，是怎么一步步被拱火拱到开地图炮的，全过程就摆在眼前。动辄把技术纠纷往民族感情上扯、顺手扣一顶 racist 的大帽子。反倒激出了一堆针对中国开发者的恶评，顺便把“中文社区玻璃心”的刻板印象又坐实了一层。

归根结底，还是松弛感的问题。心里有底气的人，听见别人调侃一句“拼夕夕版”，顶多乐一下，回头把代码写漂亮；紧绷得要命、听不得半句调侃的，恰恰显得底气不足，敏感脆弱玻璃心了。

## 别再霍霍中国开发者的声誉了

实话实说，中国在国际开源社区的声誉本来就没那么好，这跟历史包袱和国情都脱不开关系。拼多多、南山必胜客，还有很多过去在开源和知识产权上的各种先例，老实说，中国开发者在国际社区的声誉，是负分起步，大家都心知肚明。

举个现成的例子：之前阿里云 RDS 推出过一个叫“RDS Supabase”的产品。Supabase 确实是开源项目，但人家的 Supabase 是正经注册商标。你自己卖商业云产品，直接顶着人家的商标去卖，以行业视角来看，是挺没道德的。后来 Supabase 的 CEO 直接在公开场合蛐蛐[^11]，说那个地方哪有黑客道德这种东西。[阿里云"借用"Supabase：开源与云的灰色地带](/cloud/aliyun-supabase/)

像国产操作系统、国产数据库这些就更不用说了。市面上两三百套国产数据库，扒开一看，半壁江山都是 PostgreSQL 的徒子徒孙。你 fork 了 PG 瞎魔改也就算了，改完还要吹嘘“百分之百自主研发”。这种事拿到国际上，观感实在太差，丢人丢到家了。

但这几年，局面其实正在实打实地扭转。最明显的，就是中国的开源大模型一波接一波在国际上嘎嘎乱杀，极受欢迎，扛起了开源（开放权重）模型的大旗，帮中国技术圈挣回了实打实的口碑。

还有一大批出海的开源基础软件正在走向世界——拿老冯自己做的 Silo 对象存储和 Pigsty 发行版来说，一大半都是海外用户。眼看着中国开源一步步洗掉过去的刻板印象，这本来是难得的大好局面。

## 声誉是攒出来的，不是吵出来的

开源这个行当，向来是有事说事，靠作品说话。老冯的看法是：别拿这些毫无意义的口水仗到处树敌。中国开发者在国际社区的声誉，从来不是靠在推特上抱团出征、扣帽子吓出来的，而是一个 commit、一个 patch、一个版本踏踏实实攒出来的。

拿我自己最熟悉的 PostgreSQL 生态来说：我折腾扩展分发，把几百个扩展打成原生 RPM/DEB 包；做本土化翻译，把简繁中文消息翻译推到 100% 覆盖、合进 PG 19；维护文档、做镜像、报上游 Bug。这些事没一件能上热搜，但做久了，社区里的人自然认你这个人。PG 圈里像厉超这样的开发者也是一样，安安静静沉下去写两年硬核代码，深度参与进入了 PG 内核社区。没人因为他是中国人就把他挡在门外，也没人因为他是中国人就给他开绿灯。代码就是代码。

当事人早就翻篇了——名字改了，歉道了，私下聊妥了，规矩也写进 `TRADEMARK.md` 了。还在场外紧绷着神经、把敏感和玻璃心一路输出到海外的，说句糙话，真就是在国际社区里拉屎。中国开发者今天挣来的每一分体面，都是前人和同行真刀真枪干出来的，自己一行代码不写，却天天在场外叭叭地消耗大家攒下来的口碑，确实挺让人讨厌的。

说到底，在推特上汪汪乱叫并没有什么用，技术圈最后认的还是产品能不能打。觉得 T3 做得不好，或者看 Theo 不顺眼，最硬核的回击方式就是去 fork 一份，换上你自己的招牌，在这个基础上把大家的痛点全给解决了，做出一个更牛逼的产品出来。真能干成这样，那你就是牛逼，不用你喊口号，全世界都会服你。

就算 Theo 在推上叭叭个没完，用户也不会因为这个就不用 T3 Code——因为它确实做得好，有啥办法？这就跟最极端仇视中国的 Anthropic 一个道理。老冯个人也很讨厌这家公司，但这不妨碍我继续用 Claude，因为它现在就是写代码最强的。

而且就算退一万步讲，老冯买一个 $200 的 Claude Ultra 订阅，一个月能薅出 1 万刀的算力。就算按它 85% 的毛利来算，它还得倒贴我一千多刀；况且我拿它干的全是公开的开源项目拿不到数据，用得越多，它亏得越多。这才是实打实地去干人家给人放血，师夷长技以制夷。

真觉得不爽，要么拿出更牛逼的产品正面硬刚，要么实打实地给对手造成伤害和扣血。躲在屏幕后面叭叭半天，既伤不了人家一根毫毛，还顺手把中国开发者好不容易攒下的声誉给霍霍了，有什么用呢？
