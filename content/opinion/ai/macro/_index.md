站在万亿美元算力基建狂潮与认知边际成本坍塌的十字路口，只看跑分评测看不到金融周期会沦为接盘侠，只看宏观研报不懂工程底座则会沦为空谈家。我将全球五层渗透漏斗、注意力硬约束、算力杠杆账本、认知通缩传导与国家主权博弈拼进同一张坐标系，拆解未来十年财富、组织与权力的真实迁徙路径。

## 一、真实渗透漏斗与五年转型窗口 {#funnel-and-window}

### 号称十亿周活，全球 AI 真实“深透率”有多高？ {#five-tier-funnel}

把网页闲聊当成掌握生产力是最大的统计错觉。补齐 Karpathy 漏斗的中间断档后，全球 AI 呈悬殊的对数五层结构：L1 聊天约 20 亿（24%），L2 桌面 Agent 周活骤降至 4500 万（深透率仅 0.55%），L3 打满 200 美元顶配约 200 万，L4 并行十几个 Agent 的舰队指挥官仅 8 万，L5 核心研发约 5000 人。腰部玩家十九个月暴涨 30～80 倍靠的是包月挂机、Codex 桌面多开与白领破圈三次工具拐点；反观 180K Star 的 OpenClaw 卖的只是手机“批奏折”爽感与卖课焦虑，真红利只属于用 SSH/tmux 驾驭原生 Coding Agent 的实干派。

- [AI 深透率，可能没那么高 · 十九个月：漏斗是怎么长出来的](/ai/funnel/#十九个月漏斗是怎么长出来的)：复盘固定月费挂机、桌面多 Agent 并行与非编程白领破圈三次产品形态拐点如何撑起腰部重度人群。

### 大厂裁员而开发招聘反涨，为何唯独写代码成了楔子？ {#coding-super-wedge}

大厂裁员与开发扩招并不矛盾：Block 裁员四成（四千余人）实为清算疫情盲目扩招、股价暴跌 75% 的管理泡沫；Citadel 数据显示 2026 年初全美软件工程师招聘反倒逆势大涨 11%，代码成本趋零正在杰文斯悖论下释放全社会增量需求。而真实 AI 商业收入之所以像钢针般死死扎在“写代码”上，是因为行业扩散受制于 `可验证性 × 可逆性 × 责任可归属` 公式——唯独软件工程兼具编译器测试验证、Git 零成本回滚与程序员合并背锅，打款、发货、做手术、签合同等其余八成行业缺物理防呆与保险认定，只能按“年”补课。

### 知识工作者为何没二十年缓冲期，五年分水岭在哪？ {#five-year-watershed}

这代知识工作者最致命的误判，是以为自己还有工业革命式二十年适应缓冲期。从发明到亿级普及，电力用了 46 年、电话 35 年、互联网 7 年，ChatGPT 仅用 2 个月，留给个体完成能力迁移的窗口已不足 5 年。技术史专碾抄写员、中级开发与翻译法务这类信息中介“中间层”，且靠残酷的代际替换而非老马车夫学开汽车完成切换，35～50 岁群体首当其冲。2026 至 2030 年正是用不用 AI 产出拉开 10～100 倍差距、不用即成“功能性文盲”的分水岭；而滞后技术一代人的 2040 年前规则真空期，既是无安全网的险境也是定义规则的最大红利期。

## 二、注意力天花板与商业入口重构 {#attention-and-entry}

### 人类注意力撞墙后，AI 变现与定价权向何处转移？ {#attention-ceiling}

全球算力消纳逃不开硬约束：\(\text{Token 消耗} \approx \text{人类注意力} \times \text{每分钟 Token 密度} + \text{机器后台自转}\)。机器可在后台海量抽卡空转，但有效商业收入终究按人类眼球结算——正如红果短剧人均单日 151 分钟见顶后供给翻十倍只会稀释流量，Vibe Coding 也已步入灵感枯竭倦怠期：开荒搭架构才需昂贵旗舰，转入日常维护后廉价小模型乃至开源模型便已够用，单 Token 边际价值正加速塌陷。当代码与内容生产无限提速，瓶颈便移向人类立项愿力、验收排坑与消费心力，左手模型、右手流量入口的分发渠道由此握住绝对定价权。

### 消费智能体抹平摩擦后，为何遭超级平台拉闸封门？ {#agent-friction-zero}

单靠聊天月费与写代码包不住云巨头每年近万亿美元的资本开支，唯有卡住几十亿人交易入口抽成的个人 Agent（现代版 PDA）才算得平大账。一旦用户习惯“有事找秘书”，商城就会沦为纯履约仓库，因此亚马逊在 Muse 登顶后火速拉闸封禁，微信与淘宝也一致祭出“Agent 版 `robots.txt`”关门自保。按 Citrini 推演，全天候比价的消费者 Agent 将彻底抹平人类惰性与信息摩擦，瓦解自动续费、保险被动续保溢价、买方房产佣金与外卖首屏锁定；机器间交易更会直接用稳定币绕开 2%～3% 信用卡交换费，击穿万事达卡与运通的支付收费站护城河。

### 席位制 SaaS 为何陷入自毁螺旋，新利润池归谁？ {#saas-spiral-and-stack}

面对 Coding Agent 让客户几周自建原型的压价威胁，在位软件商不会保守等死，反而迫于股价压力激进裁员买 AI。但按 Citrini 推演，当大客户借 AI 裁员 15% 时，ServiceNow 等按人头席位收费的软件巨头收入会同步机械缩水，倒逼其再裁员买算力——每家公司的个体理性自救，汇成了毫无刹车的集体自毁螺旋。而在重构后的智能体产业栈里，利润池将严格复刻云计算三级分化：基础大模型在同质化价格战中退化为低毛利 Token 水电厂（IaaS），通用 MCP 工具商占据 50% 毛利的 PaaS 位，直接替代白领岗位的垂直行业 Agent 则独享 70% 以上毛利的新 SaaS 红利。

## 三、算力金融泡沫与暗光纤红利 {#bubble-and-dark-fiber}

### 模型能力陡升，算力循环融资账本为何逼近断裂点？ {#three-curves-and-spv}

看清泡沫须先拆开三条不同步的曲线：当前模型智力曲线仍在按季陡升，全美企业真实扩散率仅两成出头（窄而深），但四大云巨头 7250 亿美元资本开支已吞噬 94% 经营现金流，透支了未来十年金融预期。更致命的是期限与信用错配：自有现金流耗尽后，算力基建转向特殊目的实体（SPV）表外加杠杆，次级债利率跳升逾 150 个基点破 10%，拿寿命仅四五年的 GPU 签下五千亿美元级十年刚性采购死约。相比有现金流打底的 Anthropic 半闭合圈，微软 6250 亿美元商业积压订单（RPO）中 45% 绑在巨额失血的 OpenAI 一家身上，这条卖方信贷闭合圈与高杠杆新云最先面临断裂。

- [AI 泡沫将如何破裂？ · 3. 时间错配与“两个循环圈”](/ai/ai-bubble/#3-时间错配与两个循环圈)：解剖四年折旧显卡背十年刚性长约的期限错配、表外 SPV 高息债定价，以及 OpenAI 与微软绑定的卖方信贷风险。

### 泡沫出清先倒哪三张骨牌，投资减速为何触发衰退？ {#dominoes-and-recession}

等待微软或谷歌宣布砍资本开支来逃顶注定滞后——身处份额囚徒困境的巨头绝不主动踩刹车，“云巨头砍 CapEx”只是 2028 年初由无公有云消化的 Meta 或高负债甲骨文亮出的最后确认牌。未来 6～18 个月先倒的三张骨牌是：SpaceX 与 Anthropic 等数千亿新股上市解禁抽血、2027 下半年吉瓦级园区并网压垮租金触发 SPV 交叉违约，以及开源模型再度刺穿前沿溢价。我对未来两年走“先杀估值、后清信用”两段式出清给出 45% 最大基准概率；且无需白领大规模失业，AI 基建已占 2026 年美国 GDP 增速约三分之一，年增 77% 的超级投资急刹车本身就会触发宏观衰退。

### 算力泡沫退潮后，一人公司如何避免沦为数字佃农？ {#dark-fiber-and-opc}

泡沫死亡恰是下半场续集开拍的前提。仅 Anthropic 就背着 8954 亿美元远期算力采购死约（一年内到期约 700 亿），通电显卡如生鲜每秒折旧；泡沫崩盘大企业退订后，会计减值抹去债务的物理显卡只要覆盖电费就会继续轰鸣，恰如 2001 年“暗光纤”喂出 YouTube，跌超九成的白菜价算力将解锁实时世界模型，并让跑通闭环的一人公司（OPC）吃上便宜十倍的过剩 Token。但退潮后按人头收费的薄壳 UI SaaS 必死，算力商品化的云巨头必在存储、托管数据库与出口流量费上死守高毛利——唯有手握可热插拔开源模型与自主跨云/本地数据底座者，才是“新自由民”而非替寡头交租的“数字佃农”。

- [AI 泡沫将如何破裂？ · 六、终局：科斯边界坍缩，我们是“新自由民”还是“新佃农”？](/ai/ai-bubble/#六终局科斯边界坍缩我们是新自由民还是新佃农)：剖析科斯企业边界向 OPC 坍缩后的终局博弈，阐明热插拔开源模型与私有数据主权为何是抵御云厂商存储与流量收租的生命线。

## 四、认知通缩、马匹困境与幽灵 GDP {#deflation-and-ghost-gdp}

### 杰文斯悖论为何救不了“马匹”，白领替代难在哪？ {#jevons-and-horses}

拿“技术革命终会创造更多岗位”安慰白领犯了致命的要素偷换错误：AI 史上首次让阅读、归纳、编码等平均认知能力按 Token 定价并在数年内暴跌一两个数量级。杰文斯悖论救得了认知总消费量，却救不了旧供给者——内燃机让运输消费暴涨百倍，马群却因市场出清工资跌破草料钱而在 1915 年后彻底崩塌。按 Citrini 推演，通用 AI 还在人类转岗目标上同步进化，且企业买 AI 属于经济越差买得越凶的运营费用替代（连带蒸发印度 IT 外包顺差）；一旦贡献全美 65% 消费的前 20% 高薪白领下沉挤压零工服务业薪资，数月储蓄缓冲耗尽后便会引爆无法自愈的可选消费断崖。

- [2028 全球智能危机 · 智能替代螺旋](/ai/2028-ai-crisis/#智能替代螺旋)：推演通用智能同步进化与逆周期运营费用替代机制，揭示高收入白领向下挤压零工市场引发的滞后消费坍塌。

### 初级岗被“上屋抽梯”，哑铃组织会埋下什么断层？ {#apprentice-crisis}

AI 抽掉的不是职场阶梯第一级，而是用“一人指挥十个订阅”直接撤走了整把初级岗梯子——斯坦福基于美国 ADP 薪资数据的研究证实，22～25 岁年轻人在高暴露职业中的就业已因校招缩减下滑约 19%，新人想上楼只剩“自己造梯子”。随着管理与外部交易成本同步暴跌，靠信息不对称与 PPT 传话的中型组织坍缩为“垄断电芯牌照的超级平台 + 接满算力的一人军团”哑铃形态，中层“AI 审核员”也因验证比生成更易自动化而只是临时收费站。企业冻结初级招聘等于吃掉自己的“种子粮”，正埋下十五年后的“学徒制断裂”危机：等最后一代踩坑熬出直觉的老手退休，谁来识破 AI 荒谬将成无解断层。
