全球 AI 坐拥二十亿聊天用户，驾驭智能体交付工程产出的真实深透率却不足 1%。当人类注意力见顶撞上万亿高息算力账本，泡沫出清后的廉价“暗光纤”红利终将归于手握私有数据的一人公司。

## 一、真实渗透漏斗与五年转型窗口 {#funnel-and-window}

### 号称十亿周活，全球 AI 真实深透率有多高？ {#five-tier-funnel}

把网页闲聊当成生产力是最大的统计错觉。补齐 Karpathy 漏斗断档后，全球 AI 呈悬殊五层对数结构：L1 聊天约 20 亿（24%），L2 桌面 Agent 骤降至 4500 万（深透率仅 0.55%），L3 顶配玩家 200 万，L4 并行十余个 Agent 的指挥官仅 8 万，L5 核心研发约 5000 人。OpenClaw 式手机套壳只卖焦虑，真红利属于用原生 Coding Agent 干活的实干派。

### 大厂裁员而开发扩招，为何唯独写代码成了楔子？ {#coding-super-wedge}

大厂裁员与开发扩招并不矛盾：Block 裁员四成实为清算疫情扩招泡沫，Citadel 数据显示 2026 年初全美开发招聘反涨 11%，印证了杰文斯悖论。AI 收入之所以扎在写代码上，是因为扩散受制于 `可验证性 × 可逆性 × 责任可归属`——唯独软件兼具编译验证、Git 回滚与署名背锅，其余八成物理行业只能按年补课。

### 知识工作者为何没缓冲期，五年分水岭在哪？ {#five-year-watershed}

脑力劳动者最大的误判，是以为自己还有工业革命式的二十年缓冲期。普及至亿级用户，电力耗时 46 年、互联网 7 年，ChatGPT 仅 2 个月，迁移窗口不足 5 年。技术史专碾信息中介层，且靠代际替换淘汰 35～50 岁存量老手；2026 至 2030 年既是拉开百倍产出的分水岭，也是 2040 年前制度真空期的红利窗。

## 二、注意力天花板与商业入口重构 {#attention-and-entry}

### 人类注意力撞墙后，AI 定价权向何处转移？ {#attention-ceiling}

算力消纳受制于 \(\text{Token 消耗} \approx \text{人类注意力} \times \text{密度} + \text{机器自转}\)，后台可无限空转，商业变现终究按眼球结算。正如短剧时长见顶后供给激增只会稀释流量，Vibe Coding 也已从昂贵旗舰开荒滑向廉价小模型维护，单 Token 价值加速塌陷。当内容与代码过剩而人类立项及验收心力恒定，手握流量入口的分发渠道将掌控终极定价权。

### 消费智能体抹平摩擦，为何遭超级平台拉闸封门？ {#agent-friction-zero}

聊天与编程订阅包不住每年近万亿美元算力开支，唯有卡住交易入口抽成的个人 Agent 才算得平大账。一旦“有事找秘书”，商城便沦为履约仓库，故亚马逊封杀比价工具，微信与淘宝也祭出“Agent 版 `robots.txt`”自保。按 Citrini 推演，全天候 Agent 将抹平续费与佣金等摩擦租金，并用稳定币绕开 2%～3% 的卡组织过路费。

### 席位制 SaaS 为何陷入自毁，新利润池归谁？ {#saas-spiral-and-stack}

面对客户用 Coding Agent 几周自建原型的压价威胁，软件商反而激进裁员买算力。按 Citrini 推演，客户借 AI 裁员 15% 会让 ServiceNow 等席位制 SaaS 收入同步缩水，汇成自毁螺旋。重构后的产业栈将三级分化：大模型沦为低毛利水电厂，通用 MCP 层占 50% 毛利，替代白领的垂直 Agent 独享 70% 以上毛利。

## 三、算力金融泡沫与暗光纤红利 {#bubble-and-dark-fiber}

### 模型能力陡升，算力循环融资账本为何逼近断裂？ {#three-curves-and-spv}

看清泡沫须拆开三条曲线：模型智力按季陡升，企业渗透仅两成，四大云巨头 7250 亿美元资本开支却已吞噬 94% 经营现金流。自有资金耗尽后，基建转向表外 SPV 加杠杆，次级债利率破 10%，拿四五年折旧的显卡背十年采购死约。微软 6250 亿美元积压订单中 45% 绑在巨亏的 OpenAI 身上，卖方信贷圈最先面临断裂。

### 泡沫出清先倒哪三张骨牌，为何减速即衰退？ {#dominoes-and-recession}

等云巨头砍预算逃顶注定滞后，囚徒困境下砍 CapEx 只是最后确认牌。未来 6～18 个月先倒的三张骨牌是：SpaceX 与 Anthropic 等新股解禁抽血、2027 下半年吉瓦园区并网违约，以及开源刺穿前沿溢价。我给“先杀估值、后清信用”两段式出清定下 45% 基准概率；AI 基建已占美 GDP 增速三分之一，投资减速即触发衰退。
