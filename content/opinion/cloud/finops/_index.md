公有云的商业底色从来不是什么高深莫测的黑科技，而是披着 API 外衣、白嫖开源生态的“赛博地主收租”。当摩尔定律让现代单机算力与 NVMe 闪存便宜到几个月云租金就能买断整套物理硬件时，穿透 5 倍算力税、30 倍对象存储税与 200 倍云盘“杀猪税”的营销迷雾，算清从 FinOps 走向下云自建的真实总账，是每一家稳态期企业夺回千万级净利润与技术自主权的必修课。

## 一、赛博地主与杀猪盘商业模型 {#cloud-business-model}

### 公有云“低价养猪、高配杀猪”如何运作？ {#bait-and-switch-funnel}

这套漏斗的核心是“低启动成本诱捕、高维持成本放血”。初创期云厂商用首单骨折与几美元核月的迷你实例赔本获客“养猪”；一旦业务上量被数据重力锁死，高配资源单价便呈阶梯跳涨——算力贵 5～10 倍、块存储贵 120～200 倍，64 核高可用云 PG 年费高达 25～217 万元（IDC 自建仅 3～4.5 万），12 节点云 MongoDB 五年折后竟要价 2300 万。几个月租金就够把生产队的驴整头买下来，听信“姿势不对”改买毛利超 50% 的托管 RDS 只会失血更惨，且遇重大故障时回旋镖照样打在业务方自己头上。

### “大客户打骨折”从何而来，为何背叛初心？ {#price-discrimination-betrayal}

云上的真实折扣纯粹是“退出权”的副产品，没有自建迁移底牌的商务谈判不叫谈判而叫求饶。AWS 之所以肯给 37signals 超低四年期 S3 价格并在离场时豁免约 25 万美元出网费，唯一原因是 DHH 团队真能随时搬走且说到做到。自建成本仅约云列表价的 0.5～1 折，能跨云下云横跳的大甲方确可逼出两折底价，但焊死在专有 PaaS 上的企业与中小开发者只能硬吞列表天价。这种拿中小客户原价血包补贴大客户的“损不足以奉有余”，混淆了硬件池化提效与封装开源收租，彻底背叛了云计算如水电般普惠中立的初心。

### 手握百倍溢价，为何本土云毛利不如挖沙子？ {#domestic-cloud-low-margin}

国际标杆 AWS 与 Azure 毛利率达 60%～70%、净利率超 30%，而手握同款百倍溢价表的国内公有云，毛利率却普遍跌至个位数到 15%（金山云甚至仅 2.1%，不如打工挖沙子赚钱）。除销售返佣内耗与重人力驻场交付外，病根在于 IaaS 与 PaaS 两头受敌：毛利超 50%、原充当暴利壁垒的“卖能力”PaaS 层被成熟开源平替击穿护城河，迫使占营收半壁江山的“卖资源”IaaS 退回标品肉搏；而在纯硬件战场上，公有云根本拼不过自带土地、廉价带宽与低息资金、敢给两折虚机与一折机柜的运营商、国资云及 IDC2.0。

### 直播卖云与公关删帖，暴露了什么行业困局？ {#livestream-and-pr-cowardice}

云计算天生是严肃的 ToB 基础设施，个人市场早被 Cloudflare、Vercel 等免费套餐覆盖；大厂跑去直播间和牙膏混卖云主机、疯抢全网分摊仅几百万“蚊子腿”营收的《幻兽帕鲁》私服、搞“买数据库送超市券”，宣告了除 GPU 租赁外传统公有云已无技术壁垒，从产品主导滑向低俗运营与价格战。正如瑞典马工在客座评论中所痛批：面对外界关于“小红书下云”的技术分析，千亿营收巨头拿不出 TCO 账本正面论战，反靠公关投诉删帖捂嘴；缺乏能讲清高阶云价值的领导者，才让国内市场困死在“租虚拟机”压价打杂的泥潭里。

### 从百年电力史看，大一统公有云终局在哪？ {#power-grid-endgame}

包揽一切的大一统公有云终将解体，重演“电网与电器彻底分离”的历史剧本。重资产的算力存储底座（IaaS）如同电力传输，经价格战洗牌与公共监管整合后，将沉淀为类似国家电网与运营商的平价公用基础设施；而数据库与中间件（PaaS/SaaS）如同冰箱洗衣机，没人会接受“为了用洗衣机必须跑到发电厂机房租工位”的荒唐模式。云厂商卖力推广的 CloudNative 开源栈（K8s、MinIO、Pigsty）已成亲手卖出的反垄断绞索，配合包网包电实价租售的 IDC2.0，终将倒逼云软件与自由软件和解、回归正常家电毛利。

## 二、算力、云盘、S3 与 RDS 扒皮 {#resource-markup-anatomy}

### 十年硬件跃升多少倍？自建核月成本多少？ {#hardware-moores-law-dividend}

被公有云 API 屏蔽底层视野的一代程序员，对十年硬件跃迁浑然不觉：双路 AMD EPYC 9754 单机已达 256 核 512 线程；Gen5 企业级 NVMe 跑出 14GB/s 带宽、270 万 IOPS 与微秒级延迟（55µs/9µs），吞吐比机械盘强万倍、延迟快千倍；万余元 100GbE 网卡也快了百倍。对账真实采购单，DHH 买断 192 核 384G 配 12TB NVMe 的戴尔整机仅 19,980 美元，五年摊销加美国机房网电代维合 **25.32 元/核·月**，与探探国内物理机全包 **19.53 元/核·月**完全印证。打破云中间商对摩尔定律红利的截留，重拾硬件常识就能夺回千万级利润。

### 摊入机房运维后，云主机纯算力贵出几倍？ {#ecs-cpu-cost-teardown}

即便彻底剔除存储只算纯 CPU，全额摊入五年折旧、机柜网电与专职运维薪酬后，本地自建仅 18～22 元/核·月（纯硬件约 10 元）；而阿里云主流实例包月 125 元、按量 187 元（贵 8 倍），锁死五年全预付放弃弹性仍需 37 元（贵一倍），AWS 同配 `c7a.metal` 按需更达自建的 10.8 倍。拆解定价可见：同族核数严格线性计价毫无规模折扣，隐含内存月租约 12 元/GiB（租俩月够买内存条），香港等海外区贵近两倍；所谓“算力大降价”因未动云盘，1 核配 64GB PL3 下综合单价仍达 165～571 元/核·月（自建的 7～25 倍）。

### 高性能云盘为何卖百倍天价做数据库锚点？ {#ebs-defensive-pricing-anchor}

一块 3.2TB 企业级 PCIe NVMe SSD 市价不到三千元，与高端云盘硬件同源，但 AWS EBS `io2` 按需价达硬件直采的 120 倍（15 天买断整盘），阿里云 ESSD PL3 高达 **200 倍**（按需不到 5 天买断，三年五折长租够买 120 多块盘）——且数据库自带多副本高可用，存储层额外三副本纯属浪费，SLA 更不敢兜底数据不丢。零运维门槛的硬盘敢卖百倍天价，实为环环相扣的“防御性定价之锚”：先将实例本地盘阉割为停机抹除的临时盘，再把唯一能跑严肃数据库的云盘定成天价，堵死客户租虚机自建数据库的退路，逼其购买高毛利 RDS。

### 为何预付越长云盘占比反升？降档有何代价？ {#essd-tier-throttling-trap}

挂载大容量云盘会让长期成本彻底畸形：本地企业级 NVMe（3M IOPS、7GB/s）五年摊销仅 0.02 元/GiB·月，而性能不及它的 ESSD PL3（1M IOPS）包月高达 4 元、三年五折封顶仍要 2 元。由于云盘封顶折扣（5 折）远弱于算力封顶折扣（3 折），在 1 核 : 64GB 标准配比下，预付期越长，存储占总账单比重反而从 67% 倒挂攀升至 **77%**！若为压低账单降级选用 PL2、PL1 或 PL0 乞丐盘，虽可将存储占比压回五成至两成，却必须吞下自废 90%、95% 乃至 **99% IOPS**（PL0 仅 1 万 IOPS、180MB/s）的性能阉割苦果。

- [剖析阿里云服务器算力成本 · 杀猪盘的价格](/cloud/ecs/#杀猪盘的价格)：对比 0.02 元/GiB·月本地 NVMe 与 4 元/GiB·月 ESSD PL3，算出折扣差导致五年预付存储占比飙升至 77% 的畸形账本。
- [剖析阿里云服务器算力成本 · 云存储对单价的影响](/cloud/ecs/#云存储对单价的影响)：量化降级选用 PL2/PL1/PL0 云盘在压缩存储账单占比的同时，如何造成最高 99% 的 IOPS 吞吐腰斩。

### 对象存储 S3 为何演变成了三十倍杀猪盘？ {#s3-markup-and-nvme-minio}

在摩尔定律面前，“降价慢于硬件跌价就是变相涨价”。2006 至 2023 年 AWS S3 标准档从 0.15 降至 0.023 美元/GB·月（2016 年冻价至今），名义降 6 倍；同期底层 HDD 却跌至 3.7%（便宜 26 倍），红利被中间商截留使 S3 硬件溢价从 7 倍飙至 **30 倍**。欧洲 Hetzner 在标准硬件上跑开源 Ceph/MinIO，以 S3 **五十一分之一**的价格盈利售卖便是铁证。如今拿不到两万元的 12TB 企业级 NVMe 套上 MinIO，五年摊销仅 14.5～23 元/TB·月，不到慢速 S3 标准档（161 元/TB·月）零头，首字节延迟还快三个数量级。

### 云数据库与伪 Serverless 为何是成本刺客？ {#rds-and-serverless-scam}

云数据库（RDS）毛利超 50%，是头号利润杀猪刀：白嫖免费开源 PG/MySQL 内核，却将自建 19 元/核·月的算力卖到阿里云 260～410 元、AWS 440～1328 元/核·月（某业务上云后年费从千万飙至近亿）。RDS 唯一合理场景仅有极早期验证与秒杀脉冲；住宅租售比几十年而 RDS 仅几个月，稳态负载长租 RDS 就像天天租共享充电宝给电脑供电。至于传统大厂吹嘘的“RDS Serverless”，大多不支持 Neon 式缩容至零，纯属共享集群按请求计费的榨钱术；既然云弹性溢价十余倍，除非峰值波动超百倍，买物理机超配十倍划算得多。

- [云数据库是不是智商税 · 成本刺客](/cloud/rds/#成本刺客)：揭露 RDS 白嫖开源内核却将 19 元/核·月硬件算力卖到上千元、支撑超 50% 毛利的暴利账本。
- [云数据库是不是智商税 · 适用场景](/cloud/rds/#适用场景)：用“天天租共享充电宝给电脑供电”与几个月租售比，界定云数据库仅适用于极早期验证和剧烈脉冲负载的边界。
- [云数据库：用米其林的价格，吃预制菜大锅饭 · 云数据库有没有啥出彩之处？](/cloud/rds-scam/#云数据库有没有啥出彩之处)：区分真 Serverless（缩容至零）与大厂伪 Serverless 计费话术，论证稳态企业超配十倍物理硬件远胜买高价云弹性。

### 存储芯片暴涨周期，租云能躲过硬件涨价吗？ {#rent-exposure-buy-hedge}

恰恰相反，租云是裸奔的硬件通胀空头敞口，提前买断自有硬件才是锁定五年成本的对冲手段。云的本质是让你永远按现货价租硬件：当 AI 基建抽干产能导致 DRAM 同比暴涨 172%、企业级 SSD 价格翻倍时，云厂商绝不会替客户扛成本，采购涨价终会通过收紧折扣、续约加价和上调列表价悉数转嫁给租户。反观提前买断硬件的自建者不仅一次性锁死了五年固定折旧，在算力与存储变成硬通货的通胀周期里，DHH 花 150 万美元买下的 18PB 全闪存储甚至实现了涨到 1900 万美元的惊人资产升值。

- [下云的人已经赚麻了 · 四、租是敞口，买是对冲](/cloud/cloud-exit-2026/#四租是敞口买是对冲)：剖析 DRAM 暴涨 172% 与 SSD 翻倍周期下的成本传导机制，复盘 DHH 150 万美元自有存储升值至 1900 万美元的实物对冲账。

## 三、计费黑箱、抽梯子与佛祖标杆 {#billing-traps-and-cloudflare}

### 比两千万错账更可怕的云计费黑箱是什么？ {#billing-blackbox-salami}

百度云凌晨上线 Bug 把 261.8KB 流量开出两千多万乃至四千五百万天价账单（1GB 折合 77 亿元）并附 15 天欠费删库通知——这种荒诞错账一眼就能识破。真正可怕的是客户根本无从技术核验的“萨拉米切片式”微小多扣费：例如十进制与二进制口径猫腻，或像此前腾讯云 CDN 仅 1GB 流量包点一次预热就暗扣大几百元内部流量费，直到被公开痛批才认错修补，此前无数没细查账单的用户早已白白认栽。计费黑盒既无常识阈值熔断又极度隐蔽，逼得客户只能像斗牛犬一样死磕明细防宰。

### 私有空 S3 桶仅暴露桶名为何会被刷爆账单？ {#s3-docc-dark-forest}

因为 AWS S3 对连身份认证都未通过的外部 `AccessDenied`（4xx）拒绝请求照单全收向桶主扣费！开发者 Maciej Pocwierz 新建的私有空桶因撞名某流行开源工具的默认备份桶名，一天内遭全球近 1 亿次未授权 PUT 请求叠加 `us-east-1` 跨区重定向计费，瞬间炸出超 1,300 美元账单，且直连 S3 API 无法前置 WAF 防护。这种把鉴权拒绝开销转嫁受害者的霸道逻辑（Route 53 查不存在记录同理），催生了公有云独有的“刷爆账单攻击（DoCC）”黑暗森林——无需破解任何密钥，仅凭桶名就能让目标破产。

## 五、无痛下云方法论与 VPS 选型 {#practical-exit-and-vps-guide}

### 下云要去机房插线并扩招运维与 DBA 吗？ {#zero-headcount-colocation}

“自建换盘丢数据”和“养不起 DBA”的祖传恐吓早已破产。DHH 团队下云前后未扩招一人（把年费 52 万美元的 OpenSearch 换为 15 万美元硬件跑开源 ES，三个月回本零增编），因为云托管与自有硬件 90% 的运维知识完全重合。现代下云根本不用自建机房拉网线：租 Equinix 等双地域商业机柜配白手套远程代维，集群层冗余让坏盘换盘像宾馆换床单一样无感，远程团队足不出户即可跑出双活高可用；而月费 200 美元的 AI 编程助手加产品化开源发行版更直接解开了技能锁定——企业迟迟不下云，多因打工人“省老板钱、冒自己险”避责自保，非一把手拍板不可。

### 脱离秒级弹性怎么扛峰值并避开商业软件坑？ {#overprovision-and-pure-oss}
