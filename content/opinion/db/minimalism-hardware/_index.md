现代全闪大内存单机早已击穿九成九企业的负载上限，盲目堆砌分布式事务与微服务纯属昂贵自残。优先解放程序员认知带宽、吃透硬件红利并握紧本地数据主权，才是极简工程正道。

## 一、分布式伪需求、反微服务与极简主义 {#distributed-and-minimalism}

### 为何分布式 OLTP 对九成九企业都是伪需求？ {#distributed-oltp-myth}

分布式事务本质是“以质换量”：阉割复杂 SQL，跨节点 Raft 共识折损逾 70% 吞吐，多组件更让排障复杂度倍增。十年间企业级 NVMe 性价比暴涨千倍、单卡达 256TB，不到十万元的 64 核单机 PG 即可扛住百万点写、两百万点查与 32TB 大表，连 OpenAI 核心也仅靠一主四十余从 PG 支撑——99% 业务终生摸不到单机天花板。

### 亚马逊都在退回单体，微服务泡沫为何集中破灭？ {#microservices-bad-idea}

在单一团队内用脆弱昂贵的网络调用替代本地函数调用，彻底违背了加尔定律。如 DHH 援引亚马逊 Prime Video 复盘所示，其微服务在预期负载 5% 时便撞上扩展墙，退回单体后成本立降 90%；Twitter 裁员九成照转更撕下冗余遮羞布，经不起 ROI 检验的拆分泡沫终将出清。

### 基础软件忙于标书打勾，会酿成什么隐形危机？ {#immune-system-silent-exit}

基础软件最致命的衰败在报表上看不出来，即充当产品“免疫系统”的一线挑剔开发者沉默撤离。当产品从“用着爽”异化为“标书打勾多”、文档写成宣传册时，懂行者不再骂娘，而是算清云溢价假账后直接拉下真开源自建高可用——这批人一走，产品的技术判断力就彻底空心化了。

### 为何“先优化碳基程序员，再优化硅基核”才划算？ {#bio-core-over-cpu-core}

如 DHH 所算，一名 20 万美元年薪程序员（碳基核）成本抵得上租用 3663 颗 EPYC 硅基核，人效提升 25% 即省近千颗 CPU。数据库瓶颈早已转向人类认知带宽：免费 PG 成熟后，死磕内核正沦为五点微利的制造业，真正的高科技溢价全在 RDS、Supabase 与 Pigsty 等解放人脑的管控层。

## 三、现代硬件红利、云存储边界与本地主权 {#hardware-storage-and-homelab}

### 对象存储能取代本地盘吗，真实适用边界在哪？ {#object-storage-vs-local-nvme}

Kleppmann 与 Riccomini 指出 S3 支持强一致与原子 CAS 后可免协调器搭起日志与列存底座，但它绝非银弹：几十毫秒延迟比本地 NVMe 慢三四个量级，亚毫秒 OLTP 仍须靠本地盘；高昂 API 与跨区流量账单省不掉；国内大量政企自建机房与信创约束更决定了不能照搬“一切上 S3”。

### 新硬件红利巨大，为何公有云上难产新一代库？ {#modern-hardware-cloud-deadlock}

如 Alex Miller 梳理，数据库服务端六成 CPU 耗在内核网络栈，唯有 1 微秒级 RDMA、去转换层的 ZNS/SmartSSD 与 Unikernel 能重塑存储与事务引擎，而显卡分析仍困于总线带宽墙。讽刺的是欧美云巨头内部独享新硬件十年，对外仅售阉割实例（唯阿里云开放通用 eRDMA），“云上买不到新硬件就没人写新库”锁死了演进。

### Agent 狂吃硬盘，如何做本地万兆分层存储？ {#pc-nas-synology-tiering}

高强度驱动 Coding Agent 极易膨胀出数 TB 镜像与产物把 8TB 笔记本吃爆，最务实的解法是万兆内网“分层治之”：用万兆群晖 SHR-1 稳保 25TB 权威主本；再给带 8 核 Zen 4 与四条 NVMe 的零刻 PC NAS 刷入 Ubuntu 与 Pigsty，组 RAID 0 消化冷素材与测试库，并跑起 `pgvector` 智能相册，七八千元即可收进桌底 12U 机柜。
