“自主可控”本该是一道关于极端断供下生产系统能否持续运转的严肃工程题，却在政策采购温室与补贴寻租中异化成了三四百款套壳数据库“大炼钢铁”的狂欢。剥开“纯血自研”与学术造词的公关画皮，算清每核专家兜底的真实定价账本，在安可国测红线内通过管控解耦保住完整 PostgreSQL 生态，回归全球开源共同体的“运维自主可控”，才是穿越国产化泡沫的唯一清醒路径。

## 一、话术破产、大炼钢铁与出租车怪圈 {#hype-and-vicious-cycle}

### “自研”与“纯血”为何一步步沦为了反义词？ {#death-of-pure-blood}

早年去小型机本质是全球同步的架构换代，初代玩家虽借民族叙事拿预算，至少在文档里明写开源来源并真磨出了原创代码。真正的拆底线发生在近三年“大炼钢铁”：国产库暴涨至三四百款，几乎抵上全球榜单半壁江山；后来者把十几年前宽松协议的开源分叉抹平血缘、贴上**“纯血”**标签领补贴，连 CMU 副教授 Andy Pavlo 编纂 `dbdb.io` 时都直言许多号称“从零革命自研”的中国库翻开源码全是 MySQL 与 PG 换皮——这等于偷走并刷爆了全行业共用的“自主”信用额度，连累真做原创的人再也无人相信。

### “焊死证伪通道”毒在哪？为何不能各打五十大板？ {#welded-falsification-and-paraquat}

比超发不可复现的最高级咒语、甚至把夸大话术平移到辅助驾驶更阴狠的，是给宣传套上立场硬壳：谁敢追问测试条件或做对比实测，等来的不是技术答疑而是动机审讯与资金彻查——这与“指鹿为马”同构，把正常的工程校验变成了高危动作。对此绝不能用“他们都一样烂”给最恶劣者发赦免令：虚荣吹牛的公司被技术批评后，私信来认账改文档的依然是要脸的工程师，反馈回路还在就能自愈；而一遇质疑就换赛道审动机、发动捂嘴攻击的公司，如同喷洒灭生性除草剂**“百草枯”**，直接毒死了整片土壤的肥力。

- [一个词是怎么死的 · 五、必须分清等级](/db/the-you-know-who/#五必须分清等级)：区分“工程师认账可自愈的虚荣病”与“捂嘴审动机的百草枯式结构性恶”，拒绝用混为一谈替最坏示范者脱罪。

### 口号竞标与信用超发留下了什么工程总账单？ {#engineering-corruption-bill}

在只认政治口号的评标场上，诚实说明“基于成熟开源内核改进”反而成了出局劣势。全行业被迫放弃做产品转向堆人做项目，拉出一百个互不兼容的驻场分支，欠下的技术债全由全国下游通宵打安全补丁买单；“只进不出、员工自提自合、定期倒代码”的单向阀假社区弄脏了开源，故障复盘也退化为删帖公关。但**政治正确修不好 OOM、民族情怀解不开死锁**，一线开发者早已用脚投票——我个人维护的开源 PG 发行版星标甚至高过大厂重金投入的分叉内核，寻租共同体终究逃不过生产故障与时间的过滤。

### 为何持牌国产库深陷“机场出租车”死循环？ {#airport-taxi-loop}

机场出租车靠专属通道牌照排几小时队博大单，遇上短途客便抱怨绕路，糟糕体验把乘客逼向网约车，反过来加剧空排与宰客的死循环。国产数据库同样深陷**“政策繁荣下的技术荒漠”**：正如 Claude Opus 4.1 研报所剖析，167 家厂商挤在强制采购温室里换皮内卷，除达梦凭党政军渠道显著盈利外，绝大多数都在烧钱亏损或靠母公司云账本输血。许多厂商花百万元办齐评测证书当“运营牌照”强卖政企计划市场，功能、性能与维保全面拉垮，越让真实用户寒心就越只能寄生于行政摊派宰客。

交叉对齐 StackOverflow 调研、DB-Engines 与墨天轮 287 款名录即可看清真实坐标：唯一挤进国际榜尾的 TiDB 使用率仅 0.20%，与榜首 PostgreSQL（45.55%）相差两百多倍；DB-Engines 收录的 46 款国产库总分仅 34.7 分，**仅占全球总盘千分之五**。满天飞的中文 PR 软文甚至能带偏大模型：同题调研中 GPT-5 Pro 轻信通稿流于天真，唯 Claude Opus 4.1 穿透迷雾直击政策套利与代差病灶。

## 二、技术底色审计：考古分叉、负价值套壳与评测呼唤 {#technical-audit}

### 所谓颠覆式自研内核，为何多是“考古学创新”？ {#archaeological-innovation}

中国主导的 OLTP 内核距世界顶尖仍有十年代差：典型代表至今以 2012 年的 PostgreSQL 9.2 为底座，如同给老桑塔纳焊火箭发动机；本土不缺顶尖内核人才，悲剧在于**“PPT 驱动开发”**逼团队把通用接口改私有、切碎生态以自证“自主”。更有打爱国牌、拉院士站台的数据库把“有界计算”吹成黑科技，剥开满屏代数公式并在其 16GB 迷你 TPC-H 实验上一验，本质竟只是给 PG 建了个普通条件索引。

- [国产数据库：我已经过了痛心疾首的阶段 · 一、用「考古学」做创新](/db/domestic-db-acceptance/#一用考古学做创新)：剖析基于 2012 年 PG 9.2 底座堆砌验收特性的十年代差，以及 PPT 驱动开发对标准接口与工程师心血的扭曲。
- [这么吹国产数据库，听的尴尬癌都要犯了](/db/domestic-db-hype/)：扒开某院士站台国产库“有界计算”论文与 16GB TPC-H 实验底裤，实锤其核心黑科技不过是 PG 条件索引。

### 同样给开源套壳，为何许多国产库做成负价值？ {#negative-value-shell}

给硬核技术套易用外壳从来不是原罪——Red Hat 与 Supabase 正是靠提供开箱即用的高可用、监控告警并放大社区生态成就百亿估值。反观信通院统计中约三分之二基于 PG 与 MySQL 魔改的国产关系库：中国大陆在 PG 全球核心组与主要贡献者中席位为零，大批套壳商对上游零回馈，却拿十几年前的老旧分叉改废标准连接池与监控接口，把社区数百个成熟扩展拒之门外，甚至故意阉割免费开源功能来推销自家组件——这是**拆免费精装房卖高价毛坯房**，拿闭源枷锁反卡国内用户脖子。

- [国产数据库：我已经过了痛心疾首的阶段 · 四、套壳不是原罪，负价值才是](/db/domestic-db-acceptance/#四套壳不是原罪负价值才是)：对比创造增量价值的良性商业外壳与改废接口、排斥插件、阉割功能的“拆精装卖毛坯”负价值套壳。
- [国产数据库是大炼钢铁吗？ · 国产化乱象](/db/great-leap-db/#国产化乱象)：结合信通院三分之二开源魔改占比与 PG 全球核心贡献零席位的反差，痛陈零回馈白嫖开源并反卡本土用户脖子的乱象。

### 拿单边客户充数，暴露了国产 HTAP 什么窘境？ {#htap-no-applause}

DB-Engines 十二年趋势显示，全球除 PostgreSQL 与 Snowflake 外集体步入下行，国内热炒的 NewSQL 分布式赛道全球热度加总不及 PG 零头，未曾辉煌便已熄火。瑞典马工核查 OceanBase 官网三大 HTAP 标杆客户更揭穿实情：两个外接同步纯当分析库用，第三个 Classin 竟在正文坦承“后续才会尝试迁移后台 OLAP 查询”——根本没启用分析功能。拿单边客户充数说明**国内尚无人为真 HTAP 买单**，靠它敲开国际市场更是痴人说梦。

- [HTAP数据库，一场无人鼓掌的演出 · Classin](/db/htap-no-applause/#classin)：瑞典马工逐字核验官网三大标杆案例，拆穿连未启用 OLAP 能力的纯交易客户都被拉来充当 HTAP 样板的尴尬。
- [国产数据库到底能不能打？ · 过气中的数据库们](/db/db-china/#过气中的数据库们)：基于 DB-Engines 十二年纵向数据，论证传统巨头与 NoSQL 集体下行、NewSQL 分布式赛道全球热度微不足道的大势。

### 为何基础软件急需“懂车帝封闭高速式”实测？ {#dongchedi-for-db}

懂车帝封闭高速智驾实测让一众吹嘘车载冰箱彩电与“遥遥领先智驾”的热门车型全军覆没，唯独死磕核心工程的特斯拉能打，精准映射了国产基础软件“骗子太多、傻子不够用”的乱象——嘴上突破天际，背地里尽干改名换皮、阉割开源与负向优化的勾当。智驾直到闹出多起人命事故才迎来高强度公开整顿；基础软件若不靠中立硬核机构尽早搭建**“封闭高速”极限测试场**测清“能用、可用、好用、敢用”的真实边界，迟早要等爆发全国性特大停机或丢数事故才被迫总清算。

- [懂车帝暴打智驾，懂库帝在哪里](/db/car-autopilot-test/)：借封闭高速智驾实测戳破营销泡沫，呼吁建立中立硬核的第三方数据库极限评测，避免用全国性生产事故为虚假宣传买单。

### CentOS 停服选谁？OpenEuler 苦在哪？ {#el-distro-and-openeuler}

经五大版本 PG 与百余插件实机 CI 验证，EL 系兼容度排序为 `RHEL = Rocky ≈ Anolis > Alma > Oracle >> Euler`：裸机生产首选 RockyLinux 8，信创合规首选龙蜥 OpenAnolis（原生包一遍过，打通统信、麒麟等十余款衍生版）。反观号称 EL 兼容的 OpenEuler 通篇破坏底层依赖，PG、Patroni、PostGIS、PgBouncer 全需重编，还因异构 LLVM 迫使扩展 JIT 重编或阉割，适配比 Debian 还苦——严守兼容兜底才是真自主，为面子硬分叉只会割裂供应链。

- [EL系操作系统发行版哪家强？ · 使用体验](/db/rhel-compatibility/#使用体验)：详述 OpenEuler 底层包冲突与异构 LLVM 导致核心数据库组件及 JIT 模块全面瘫痪、被迫重编的工程苦役。
- [EL系操作系统发行版哪家强？ · 一些感想](/db/rhel-compatibility/#一些感想)：对比 OpenAnolis 兼容兜底与 OpenEuler/openGauss 强行魔改分叉的路线分野，阐明不折腾用户的运维自主可控正道。

## 三、路线收敛、商业定价与国测应对指南 {#pricing-and-compliance}

### 为何国产数据库硬仗本质是“含 P 量”内战？ {#pg-purity-civil-war}

PostgreSQL 正如 Linux 般吞噬整个数据库世界，裸内核早已不再稀缺——死磕内核的 MariaDB 濒临退市，包装开源卖 RDS 的 AWS 却登顶全球第一。国产库之争实质已收敛为 PG 生态内战，战力全看版本新、魔改少的**“含 P 量”**：OceanBase 押注伪需求分布式与见顶的 MySQL 属双重误判；PolarDB 回归共享存储集中式、紧贴 PG 14 且克制魔改以复用社区插件与管控，远比基于 PG 9.2 改得面目全非的 openGauss 更能打。

- [国产数据库到底能不能打？ · 改头换面的 PostgreSQL 内战](/db/db-china/#改头换面的-postgresql-内战)：提出衡量国产库战力的“含 P 量”标尺，并以 MariaDB 与 AWS 的商业反差论证决胜战场已从裸内核转向服务与管控整合。
- [20刀好兄弟PolarDB：论数据库该卖什么价？ · 数据库老司机评论](/db/cheap-polar/#数据库老司机评论)：对比“分布式+MySQL”双重误判与“集中式+少魔改 PG 主干”路线，指明依托开源主干做好本地 RDS 交付才是康庄大道。

### 告别盲目分布式，本土库真正的硬核增量在哪？ {#centralized-and-modern-hw}

OLTP 内核历经四五十年演进已成熟见顶，当代单机柜池化算力更超出绝大多数需求几个数量级，盲目炒分布式或单厂硬分叉对抗全球开源共同体纯属弯路。真正的增量方向是 **100% 兼容上游 PostgreSQL 生态**：横向用插件机制深耕垂直“扩展”，整合周边打造开箱即用的“发行版”；纵向深度压榨 Intel AMX 指令集、16TB CXL 内存池与 Gen6 SmartSSD 等新硬件——仅 AMX 加速就能让 PG 向量检索比专用库 Milvus 快一倍。

- [国产数据库里有能打的吗？ · 路走对了：集中式+利用硬件](/db/domestic-db-any-good/#路走对了集中式利用硬件)：论证单机柜算力过剩时代集中式架构的回归，展示融合 AMX 指令集、16TB CXL 内存池与 SmartSSD 让 PG 向量性能翻倍的实效。
- [数据库真被卡脖子了吗？ · 出路会在哪里？](/db/db-choke/#出路会在哪里)：阐明成熟 OLTP 时代放弃恶性硬分叉、转向“垂直插件扩展”与“开箱即用发行版”两条增量价值路径。

### 数据库公允价是多少？云账单过多少必须下云？ {#fair-pricing-and-cloud-exit}

服务器折旧仅 60～300 元/vCPU·年，开源 PG 更把软件许可证价值打归零，击穿了 Oracle 每核 12.7 万授权加 2.8 万年费的垄断溢价。无论富士通、EDB 订阅还是国际云 RDS（150～250 美元/vCPU·月），全球公允价均收敛在 **1～2 万元/vCPU·年**（国内卷至 3～5 千元），本质卖的全是专家兜底。云 RDS 按 `y = a * vCPU` 线性收费仅适合中小企业省起步费；满百核即可百万年薪买断专家压平成本（如米哈游下云砍掉近四亿预算）——云年消费过百万该算账，过千万必须下云。

- [20刀好兄弟PolarDB：论数据库该卖什么价？ · 数据库自建要多少钱？](/db/cheap-polar/#数据库自建要多少钱)：拆解硬件折旧、Oracle 垄断溢价与国际订阅/RDS 账单，确立“每核每年 1～2 万元本质买专家兜底”的公允定价锚点。

### PolarDB 央行报 130 元每节点是市场常态吗？ {#twenty-dollar-polardb}

绝非市场常态，而是云巨头失血后杀向线下信创战场的战术搅局。即便一台 4 核 8 线程的低配节点，若包含正经的原厂专家兜底支持，合理年费也应在 10 万元左右；央行招标中单节点 **130 元（约 20 美元）、维保 1 分钱**的极端报价，连销售收款的打车费都不够。这一反常低价源于头部互联网大客纷纷下云，重创了高达 50%～70% 毛利的公有云数据库利润池，倒逼云大厂猛攻私有化信创第二战场，不惜倒贴钱也要抢下顶级金融机构的标杆背书。

### 国测榜单有何悖论？为何 PG 没能迅速清场？ {#national-test-paradox}

两批安全可靠测评（国测）划定了政企关系库硬圈子，却构成荒诞悖论：榜上近半是开源 PG 的套壳子孙，血统纯正的原版 PG 反因缺中国主导核心团队被判“不自主”，给三百多家套壳库留出寻租温室。一线团队常在边缘 OA 摆国产库当**合规稻草人**而核心照跑原生 PG，大行干脆把自用 PG 打包成内部“国产库”，普通政企则借道开源高兼容的国测分支自救；而数据库真正的“DeepSeek 清场时刻”，仍有待本土团队依托国际开源用裸机 RDS 数量级降本掀桌。

### 必选国测产品时，如何花小钱兼得面子与里子？ {#decouple-ms-and-db}

闭源黑盒的套壳库倒贴钱都别碰；最务实的解法是将**管控平台（MS）与数据库内核（DB）解耦**。选购国测名单里魔改最小、“含 P 量”最高、免绑 K8s/Docker 容器底座即可直跑 Linux 裸机的开源内核（如单节点每年 5～10 万元明码标价、体验等效 PG 14 的 PolarDB PG 或 Oracle 兼容版）搞定审计面子；再配同时兼容原生 PG、PolarDB、IvorySQL 与 Babelfish 的本地管控平台（如 Pigsty），花小钱即可保住完整 PG 生态与退回原生 PG 的自由。

## 四、卡脖子真相、九级主权模型与开源正道 {#sovereignty-and-oss-way}

### 开源库真会被卡脖子吗？谁在盼着把大门关死？ {#chokehold-myth}

Linux 与 PostgreSQL 等全球宽松开源项目根本无法被单一国家封锁；卖力渲染“卡脖子”焦虑、盼着大门关死的，恰恰是眼红 Oracle 暴利的套壳商。它们把开源 PG 硬分叉改名、掺混淆代码凑“100% 自主率”并排斥原生开源，企图垄断**“独占翻墙权”**把开源面包屑卖出景区高价水的天价。强推劣质魔改库如同“IT 预制菜进校园”，迫使用户削足适履踩坑、工程师耗死在关系喂食的“数据库过家家”里，国家实质安全反因脱离全球供应链而受损。

- [数据库真被卡脖子了吗？ · 垄断关系生意](/db/db-choke/#垄断关系生意)：揭穿套壳商借安全焦虑排斥原生开源、企图关门垄断“技术输液管”把免费开源卖出天价的寻租算盘。
- [数据库真被卡脖子了吗？ · 谁受到了伤害？](/db/db-choke/#谁受到了伤害)：以“IT 预制菜进校园”痛陈强推劣质魔改国产库对业务稳定性、研发工程师尊严与国家实质软件供应链的三重伤害。

### 真需要“内核自研”还是断供不停的“运维可控”？ {#ops-sovereignty}

自主可控最朴素的底线只有一条：打仗吃制裁断供后，现有业务系统还能不能继续跑——核心在**“运维自主可控”**而非华而不实的“内核自研”。软件价值在使用中实现，全球开源已解决内核研发，除非单团队修 Bug 速度能跑赢全球社区，否则硬分叉纯属挥霍人才。2022 年西方软件撤出俄罗斯后，俄金融系统凭约 30 款本土库与紧跟主干的 Postgres Pro、ClickHouse 从容御敌；反观拉分支改名筑墙的伪自主，几年后连合并上游安全补丁的能力都会退化。

### 按九级金字塔算，带授权锁的伪自研为何是倒退？ {#nine-level-pyramid}

在 L1（远程 SaaS）到 L9（社区发布权）的自主可控九级金字塔中，无限制本地运行处于 L3，开源基础软件天然坐落在 L4（握有源码可编译重分发），具备紧跟主干与独立修补兜底能力即达 L5，务实策略应是**“去二保三争五”**。反观某些标榜“自研”却捆绑定期 License 授权文件、到期断供即停机的国产商业库，实质可控等级从开源 L4 倒退回了 L2（受限二进制）——把成熟国外软件换成随时可能破产倒闭的国内土作坊死锁，纯属自己卡自己脖子。

据 Steven Vaughan-Nichols 报道，瑞士通过 EMBAG 法案确立**“公共资金，公共代码”**原则，强制公共机构软件默认开源。回看瑞士最高法院 2011 年开源 Open Justitia 遭专有软件商 Weblaw 阻击拉锯十余年、以及美国仅要求开放 20% 代码的弱约束教训可知，唯有刚性立法才能击穿商业利益集团锁定。反观套着 PG 外壳死磕“Oracle 一行代码不改兼容”路线，走通也只会沦为五点微利的 PC 组装式低端制造；彻底拥抱“开源共产主义”才是后发国家破局王道。

CSDN 调研中超七成开发者对国产库印象负面，病根在于骗补凑数的“卫星产品”污染了标签；但直面全球市场真刀真枪搏杀的中国民营力量已脱颖而出：阿里云 PolarDB 成为唯一进入 Gartner 领导者象限的非美国数据库，TiDB 率先打入 StackOverflow 全球榜单，Pigsty、Bytebase、KubeBlocks 以及 IoTDB、TDengine 也在海外赢得口碑。事实证明，能卡住**全球软件供应链生态位**的精品，永远诞生于残酷的国际竞争而非温室保护。

### 合规脱钩锁死跨国采购后，本土开源库如何出海？ {#geopolitics-and-oss-dumping}

地缘政治敏感如今已双向锁死中美基础软件的跨国商业采购：正如国内央国企信创排斥美国背景软件迫使 EDB 只能贴牌合作，美国企业为规避监管麻烦，对带有中国公司或中国国籍创始人背景的商业数据库服务同样一刀切拒之门外。认清这层现实后，最清醒的破局姿态是商业上深耕亚洲本土与周边服务基本盘，同时在欧美市场以纯免费开源发行版大搞**“软件共产主义”零元倾销**——既然商业直销过不去政治墙，就用无国界的纯粹开源软件直接掀翻海外高价云 RDS 的饭桌。
