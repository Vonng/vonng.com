近三年国产数据库暴涨至近三百款，却深陷政策温室套利与旧版开源换皮的怪圈。唯有剥离水军软文、审计远古分叉与负价值魔改的底色，靠硬核实测重建证伪回路，才能终结信任破产。

## 一、话术破产、大炼钢铁与出租车怪圈 {#hype-and-vicious-cycle}

### “自研”与“纯血”为何一步步沦为了反义词？ {#death-of-pure-blood}

“纯血”沦为反义词，源于近三年国产库暴涨至三四百款的“大炼钢铁”刷爆了全行业的自主信用。初代玩家尚且明写开源来源并磨出原创代码，后来者却把旧版宽松开源分叉抹去血缘、贴上“纯血”标签骗补；连 Andy Pavlo 编纂 `dbdb.io` 时都直言许多中国“从零自研”库翻开全是 MySQL 与 PG 换皮，彻底连累了真原创者。

### “焊死证伪通道”为何比虚荣吹牛更阴毒百倍？ {#welded-falsification-and-paraquat}

给技术宣传套上立场硬壳、把工程校验变成动机审讯，才是毁掉行业的灭生性“百草枯”。谁敢追问测试条件或做对比实测，迎来的不是答疑而是捂嘴与背景彻查，彻底废掉了纠偏机制。对此绝不能用“都一样烂”替首恶脱罪：被批后认账改文档的仍是可自愈的虚荣工程师，焊死证伪通道则是毒死整片土壤的结构性恶。

### 为何持牌国产库深陷“机场出租车”死循环？ {#airport-taxi-loop}

持牌国产库正像靠专属牌照排队宰客的机场出租车，体验越烂越把用户逼走，最终只能寄生于行政摊派。如 Claude Opus 4.1 研报所示，167 家厂商挤在采购温室换皮内卷，除达梦外普遍烧钱亏损；靠百万测评证书圈地强卖却维保拉垮，深陷“政策繁荣、技术荒漠”死循环。

### 剥离水军软文，国产库在全球真实体量有多大？ {#global-footprint-and-llm-audit}

剥去公关滤镜，国产数据库在全球市场存在感仅占千分之五。交叉核对 StackOverflow、DB-Engines 与墨天轮 287 款名录：唯一挤进国际榜尾的 TiDB 使用率仅 0.20%，不及榜首 PostgreSQL（45.55%）零头；46 款上榜国产库总分仅 34.7 分。漫天中文软文甚至骗过了天真的 GPT-5 Pro，唯独 Claude Opus 4.1 穿透迷雾看清了代差真相。

## 二、技术底色审计：考古分叉、负价值套壳与评测呼唤 {#technical-audit}

### 所谓颠覆式自研内核，为何多是“考古学创新”？ {#archaeological-innovation}

国产 OLTP 内核距世界顶尖仍有十年代差，典型代表至今以 2012 年的 PG 9.2 为底座，宛如给桑塔纳焊火箭。“PPT 驱动开发”逼团队把标准接口改私有以自证自主；更有院士站台的国产库将“有界计算”吹上天，扒开论文与 16GB TPC-H 实验一看，底裤竟只是个普通 PG 条件索引。

### 同样给开源套壳，为何许多国产库做成负价值？ {#negative-value-shell}

套壳不是原罪，Red Hat 与 Supabase 靠交付高可用和生态增值成就百亿估值；做减法的魔改才是毒瘤。国内三分之二关系库源自 PG 与 MySQL，但 PG 全球核心贡献大陆席位为零：套壳商零回馈上游，却拿陈年分叉改废标准接口、排斥数百插件，甚至阉割开源功能卖收费组件，纯属拆精装房卖高价毛坯。

### 拿单边客户充数，暴露了国产 HTAP 什么窘境？ {#htap-no-applause}

国产厂商热炒的 NewSQL 与 HTAP 在全球热度不及 PostgreSQL 零头，国内真实市场更无人为“真混合负载”买单。DB-Engines 十二年趋势中除 PG 与 Snowflake 外集体下行；瑞典马工逐字核查 OceanBase 官网三大 HTAP 标杆客户更揭穿底牌：两家外接同步纯当分析库用，第三家 Classin 甚至坦承尚未迁移后台 OLAP 查询，全靠单边客户充数。

### 为何基础软件急需“懂车帝封闭高速式”实测？ {#dongchedi-for-db}

基础软件若不靠中立极限实测戳破泡沫，迟早要用全国性停机或丢数事故总清算。懂车帝封闭高速测试让吹嘘“遥遥领先”的车企全军覆没、唯特斯拉过关，精准映射了国产库改名换皮与负向优化的乱象。行业急需硬核第三方“懂库帝”搭起极限测试场，提前测清可用与敢用的真实边界。

- [懂车帝暴打智驾，懂库帝在哪里](/db/car-autopilot-test/)

### 红帽系替代选谁，为何慎碰魔改的欧拉系统？ {#el-distro-and-openeuler}

经五大版本 PG 与百余插件实机 CI 验证，EL 系兼容度排序为 `RHEL = Rocky ≈ Anolis > Alma > Oracle >> Euler`：裸机首选 RockyLinux 8，信创首选原生包一遍过的龙蜥 OpenAnolis。反观号称兼容的 OpenEuler 通篇破坏底层依赖，PG、Patroni、PostGIS 全需重编，异构 LLVM 更迫使扩展 JIT 阉割，适配比 Debian 还苦——严守兼容兜底才是真自主。
